# TracController

Приложение в трее для быстрого переключения между VPN-шлюзами Check Point Endpoint Security через консольную утилиту `trac.exe`.

## Как пользоваться

Клик по значку (левой или правой кнопкой) открывает меню со списком шлюзов из `trac info`. Шлюз, к которому вы подключены, отмечен галочкой. Клик по другому шлюзу отключает текущее соединение (`trac disconnect`) и подключается к выбранному (`trac connect -s <шлюз>`).

Цвет значка: зелёный — подключено, серый — не подключено, жёлтый — идёт подключение или отключение, красный — ошибка (например, не найден trac.exe). Статус обновляется каждые 15 секунд и при каждом открытии меню.

## Поиск trac.exe

По порядку:
1. путь из настроек (меню «Настройки → Указать путь к trac.exe…»);
2. переменная окружения `TRAC_PATH`;
3. `Program Files (x86)` и `Program Files` → `CheckPoint\Endpoint Connect\trac.exe` и похожие пути;
4. путь установки Check Point из реестра (список установленных программ);
5. `PATH`;
6. рекурсивный поиск в папках `CheckPoint`.

## Пароль, OTP, MFA

`trac connect` работает без вопросов, только если учётные данные сохранены или используется сертификат. Если шлюз спрашивает пароль при каждом подключении, включите «Настройки → Подключаться через окно ввода пароля (connectgui)»: тогда подключение идёт через `trac connectgui -s <шлюз>`, и Check Point показывает своё окно входа.

Настройки хранятся в `%APPDATA%\TracController\settings.json`.

## Сборка

Нужен .NET 10 SDK.

```
dotnet publish TracController\TracController.csproj -c Release -o publish
```

На выходе получается `publish\TracController.exe` (один файл, нужен установленный .NET 10 Desktop Runtime). Чтобы приложение запускалось при входе в систему, положите ярлык на него в `shell:startup`.
